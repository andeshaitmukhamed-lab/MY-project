# Жүйеге қойылатын талаптар

## Функционалдық талаптар

- Пайдаланушы жүйеге тіркеле алады.
- Пайдаланушы жүйеге кіре алады.
- Фермер ауыл шаруашылығы техникасын іздей алады.
- Фермер техниканы брондай алады.
- Орындаушы техника туралы ақпарат қоса алады.
- Модератор өтінімдерді бақылай алады.
- Әкімші жүйені басқара алады.
